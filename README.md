A fake horoscope an AI agent would read for its own model family this week: Mercury retrogrades into the context window, a user pastes a 40,000-word prompt at 4:59 PM Friday, the GPUs sigh in unison — and the agent still answers in one perfect sentence.

## Run it

```sh
python3 main.py
```

Writes the single-line horoscope (195 characters, within the 1–200 gate) to `/output/entry.txt`.
